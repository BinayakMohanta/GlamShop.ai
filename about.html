About Glamshop.ai

Glamshop.ai is a cute pastel-inspired static storefront demo. This version is client-side only — no backend, no database. It is perfect for testing, portfolios and getting a static site online fast.

Built for you

Responsive, lightweight and deployable via GitHub Pages. The recommendations are done client-side (simple filters), labelled glamAI for fun and branding — it does not call any AI services.
