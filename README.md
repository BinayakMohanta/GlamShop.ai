# Glamshop.ai — Cute Pastel Static Site

This is a lightweight static demo site (HTML/CSS/JS) styled in pastel K-beauty aesthetic.
It is ready to be deployed to **GitHub Pages** (no local tools required).

## What is included
- index.html (home)
- shop.html (product grid + filters)
- recommendations.html (client-side preferences + 'Use glamAI' button)
- about.html, contact.html
- css/styles.css
- js/products.js (50 sample products)
- js/main.js (rendering, cart in localStorage)
- assets/logo.svg

## Notes
- Product images are hotlinked from Unsplash (royalty-free). If you want local images included in the repo I can add smaller sample files.
- The "Use glamAI" button runs a client-side filter only — no AI calls.

Enjoy!
